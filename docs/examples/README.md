# Record examples

These are complete records copied from version 1.0.0 to illustrate each record type:

- [Data](data.json): DiTEC-WDN hydraulic scenarios.
- [Model](model.json): pandapower.
- [Platform](platform.json): OpenDSS.
- [Case study](case_study.json): London Tube strikes and bikeshare use.

For a new record, assign a new ID and replace every resource-specific value with source-supported metadata. Do not reuse an example's sources, licence, dates or relationships without evidence. The maintained records live in `catalog/<type>/`; these examples are teaching copies.
