# Interpreting the catalogue

This catalogue is a discovery aid. It does not guarantee that a resource is suitable, current, complete, accurate or available for a particular study.

- Coverage differs by sector, country, language and provider. Absence from the catalogue does not establish that a resource does not exist.
- Metadata summarise source descriptions. English display titles and category assignments may simplify those descriptions. Read original documentation before selecting a resource.
- Dates identify recorded catalogue events. `date_verified` is a metadata check date; it does not mean a dataset was downloaded or a model was executed. `description_checked` and link observations describe specific checks, not a general certification.
- Link availability changes. Authentication, geographic restrictions and temporary service failures can affect access. A successful HTTP response does not prove that the page contains the intended resource.
- Licence and access fields refer to the described resource. Different components or versions may use different terms. An unstated licence is not permission to reuse.
- Resources with related names or overlapping scopes may remain separate records. Check provider identifiers and versions when combining them.
- Stated simulation uses may include interpretations based on metadata. They do not demonstrate performance in a particular application.
- The full catalogue is large. First loading and indexing can take time, particularly on mobile devices or slow connections. Filtering occurs in the browser after loading.

Corrections and source-backed additions are welcome through the repository's issues and pull requests.
