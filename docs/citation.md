# Citation

Please cite the catalogue version used in your research. The repository supplies machine-readable citation metadata in [CITATION.cff](../CITATION.cff). GitHub's “Cite this repository” control can export a citation.

Kammouh, O. (2026). *Data catalogue for critical infrastructure research* (Version 1.0.0) [Computer software and metadata catalogue]. Zenodo. https://doi.org/10.5281/zenodo.23143543

- Version 1.0.0 DOI: [10.5281/zenodo.23143543](https://doi.org/10.5281/zenodo.23143543).
- Concept DOI for all versions: [10.5281/zenodo.23143542](https://doi.org/10.5281/zenodo.23143542).

A release archive fixes the records and software for a version. A version DOI identifies that fixed release; a concept DOI identifies the project across versions. Use a version-specific citation for reproducible research. The hosted dashboard may display a newer snapshot than a previously cited release.

Also cite the original datasets, models, platforms and case-study publications that you use. The catalogue is a discovery source and does not replace provider attribution or licence requirements.
