# Changelog

## Website updates after 1.1.0

- Fix mobile filter scrolling by bounding the panel to the viewport, including portrait and landscape layouts.

- Keep the welcome instructions closed on first visit. Open help only when the visitor selects the question-mark button.

- Add a visible GitHub link in the dashboard header and an explicit public repository link in the footer.

- Add an InfraData skyline connected to data nodes to the header, browser bookmarks and home-screen icons. The catalogue is unchanged; these website assets are not part of the fixed 1.1.0 archive.

## 1.1.0, 11 October 2026

- Refresh the catalogue to 68,670 resources, a net increase of 4,045 since version 1.0.0.
- Add the Data resource filter, with 467 data catalogue links, and catalogue membership groups.
- Include the latest reviewed metadata corrections and approved exclusions.
- Reduce initial dashboard data to about 58 MB. Load full metadata on demand for details and exports.
- Create large filter controls only as needed and preserve all search words.
- Keep the private working catalogue and public export connected through a checked import policy.


- Remove four transport-resource links containing embedded access keys. Dataset landing pages remain available.
- Reject credential-shaped values during public checks, snapshot imports, site builds and release packaging.

## 1.0.0 archive correction, 5 October 2026

- Remove the four keyed links from the published source history and tagged archive.
- Replace the compressed exports, checksums and Zenodo ZIP while retaining all records and existing DOIs.

## 1.0.0

First public release of the Data catalogue for critical infrastructure research.

- 64,625 metadata records covering data sources, models, simulation platforms and case studies.
- Static dashboard with search, combined filters, resource details, shared URLs and CSV/JSON exports.
- Documented schema, source-based methods, research examples and contribution process.
- Independent build, automated checks and a conflict-aware snapshot import command.
