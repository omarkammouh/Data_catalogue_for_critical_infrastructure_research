# Changelog

## 1.0.0

First public release of the Data catalogue for critical infrastructure research.

- 64,625 metadata records covering data sources, models, simulation platforms and case studies.
- Static dashboard with search, combined filters, resource details, shared URLs and CSV/JSON exports.
- Documented schema, source-based methods, research examples and contribution process.
- Independent build, automated checks and a conflict-aware snapshot import command.
